# Zero AI

Zero AI is an AI-powered chat application designed to provide an interactive conversational experience. It allows users to ask questions and receive AI-generated responses while maintaining context through conversation history.

## 📂 Project Structure

The project is organized into separate directories to keep the frontend and backend independent and maintainable.

```text
zero-ai/
├── api/
│   └── README.md
├── frontend/
│   └── README.md
├── README.md
└── LICENSE
```

### 🔗 API

Contains the backend responsible for processing chat requests, handling questions, managing conversation history, and communicating with the AI service.

For more information, see [`api/README.md`](api/README.md).

### 💻 Frontend

Contains the user interface, including the chat experience and communication with the backend API.

For more information, see [`frontend/README.md`](frontend/README.md).

## 🛠️ Technologies

- Node.js
- Vue.js
- Axios
- REST API
